# 이벤트에 대한 것.

본 문서는 완벽한 이해가 아닌 프로젝트 목표 달성을 위해 훑어본 간략한 지식의 모음.
참고하지 말것.

이벤트 발생시 호출할 함수 = 이벤트 핸들러  
이벤트 발생시 브라우저에게 핸들러의 호출을 위임하는 것 = 이벤트 핸들러 등록

이벤트 핸들러를 등록해서 특정 상황이 오면 이벤트 핸들러를 호출함.

## 이벤트 타입

### 마우스 이벤트

- click
- dbclick
- mousedown
- mouseup
- mousemove
- mouseenter
- mouseover
- mouseleav
- mouseout

### 키보드 이벤트

- keydown
- keyup

### 포커스 이벤트

- focus
- blur
- focusin
- focusout

### 폼 이벤트

- submit
- reset

### 값 변경

- input input 요소의 값이 입력되었을 떄
- change input 요소의 값이 변경될 떄
- readystatechange HTML 문서의 로드와 파싱 상태를 나타내는 document.readyState 프로퍼티 값이 변경될 떄

### DOM 뮤테이션

- DOMContentLoaded HTML 문서의 로드와 파싱이 완료되어 DOM 생성이 완료되었을 떄

### 뷰 이벤트

- resize 브라우저 윈도우의 크기를 리사이즈 할 때
- scroll 웹 페이지 또는 HTML 요소를 스크롤 할 떄

### 리소스 이벤트

- load DOMContetnLoaded이벤트가 발생한 이후 모든 리소스의 로딩이 완료되었을 때
- unload 리소스가 언로드 될 떄
- abort 리소스 로딩이 중단시
- error 리소스 로딩 실패시

이벤트 핸들러를 바인딩하는 법

- 이벤트 타깃. on+이벤트타입 = function(){};

> 하나의이벤트 핸들러만 바인딩 할 수 있다는 단점이 존재.

- EventTarget.addEventListener('eventType', functionName [,useCaputre]);

> 둘 이상의 이벤트 핸드러를 등록할 수 있고, 등록된 순서대로 호출된다.

- EventTarget.addEventListener('eventType', functionName [,useCaputre]);

> 제거법. 제거하려면 모든 인수가 정확히 일치해야 제거 된다.
