# DOM document object model

본 문서는 완벽한 이해가 아닌 프로젝트 목표 달성을 위해 훑어본 간략한 지식의 모음.
참고하지 말것.

DOM은 HTML의 문서의 계층적 구조와 정보를 표현하며 이를 제어할 수 있는 API다.

HTML의 요소와 노드 객체

```HTML
<div class="greeting">hello</div>
<div > 시작태그
class 어트리뷰트 이름
"greeting" 어트리뷰트 값
hello 콘텐츠
</div> 종료태그
```

HTML 요소는 요소 노드 객체로 변환.  
어트리뷰트는 어트리뷰트 노드로  
텍스트 콘텐츠는 텍스트 노드로 변환된다.

요소 간에는 중첩 관계에 의해 계층적 부자관계를 형성.  
이러한 요소간 간 부자관계를 반영하여 트리자료 구조를 구성한다.

트리자료 구조는 노드들의 계층구조로 되어있다.  
부모노드와 자식 노드가 있고, 하나의 최상위 노드에서 시작한다.  
최상위 노드는 부모 노드가 없으며 루트 노드라고 한다  
루트 노드는 0개 이상의 자식 노드를 갖고  
자식 노드가 없는 도르를 리프노드라고 한다.  
노드 객체들로 구성된 트리자료 구조를 DOM 이라고 한다.

문서노드 document node는 DOM 트리의 최상위 노드.
window의 document 프로퍼티에 바인딩 되어 있다.

## 요소 노드 취득

- id를 이용한 요소 노드 취득
  document.getElementById();

같은 id가 여러개 있으면 첫 번째 요소 노드만을 반환한다.  
요소가 존재하지 않는 경우 null을 반환한다.

id 어트리뷰트를 부여하면 동일한 이름의 전역 변수가 암묵적으로 선언되고 해당 노드 객체가 할당되는 부수 효과가 존재한다.  
이미 id와 같은 이름의 전역변수가 있으면 노드 객체가 재할당되지 않는다.

- 태그 이름을 이용한 요소 노드 취득.
  document.getElementsByTagName();
  elements라 배열 형태로 여러개 반환함.  
  유사 배열객체이며 이터러블임.

- class를 이용한 요소 노드 취득
  document.getElementsByClassName();

- css 선택자를 이용한 요소 노드 취득
  ()안에 들어갈 수 있는 값의 종류

> -
* 전체 : 모든 요소 선택
> - 특정 태그 : 특정 태그 요소 모두 선택
> - #foo : id 값이 foo인 요소를 모두 선택
> - .foo : class 값이 foo인 요소를 모두 선택
> - input[type=text]: 인풋 요소 중에 type 어트리뷰트 값이 text인 요소를 모두 선택
> - div p: div 요소의 후손 요소 중 p 요소를 모두 선택
> - div > p: div 요소의 자식 요소 중 p 요소를 모두 선택
> - p + ul:p 요소의 형제 요소 중에 p 요소 바로 뒤에 위치하는 'ul 요소'를 선택
> - p ~ ul:p 요소의 형제 요소 중에 p 요소 뒤에 위치하는 'ul 요소'를 모두 선택
> - a:hover: hover 상태인 a 요소를 모두 선택
> - p::before: p요소의 콘텐츠 앞에 위치하는 공간을 선택.

document.querySelector();

- 만족하는 요소 노드가 여러개인 경우 첫 번째 요소만 반환
- 존재하지 않는 경우 null 반환
- css 선택자가 문법에 맞지 않는 경우 DOMException 에러 발생

document.querySelectorAll()

- 만족시키는 요소가 존재하지 않는 경우 빈 NodeList 객체를 반환
- css 선택자가 문법에 맞지 않는 경우 DOMException 에러 발생

Eelement.matches()

- 인수로 전달한 css 선택자를 통해 특정 요소 노드를 취득할 수 있느지 확인

## 노드 조작

Elements.nodeValue = '';  
텍스트 노드의 값을 변경할 수 있다.

Element.textContent = '';
요소 노드의 텍스트를 모두 취득하고 html 마크업은 무시한다.

Element.innerHTML = '';
HTML마크업이 파싱되어 요소 노드의 자식 노드로 DOM에 반영된다.

## 어트리뷰트 조작

### 초기값 관리

Element.getAttribute(어트리뷰트명); 값 불러오기  
Element.setAttribute(어트리뷰트명, 어트리뷰트값);
Element.hasAttribute(어트리뷰트명); 존재 확인
Element.removeAttriubte(어트리뷰트명); 어트리뷰터 삭제

### 변경값 혹은 최신화 관리

document.getElementById().getAttribute();
document.getElementById().setAttribute();

### data 어트리뷰트와 dataset 프로퍼티

data- 뒤에 임의의 이름을 붙인 사용자 정의 어트리뷰트  
dataset.어트리뷰트이름으로 접근 가능
