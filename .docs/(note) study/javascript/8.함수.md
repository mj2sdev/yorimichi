# 함수의 정의

값을 입력받아 정해진 처리 후 출력하는 것.  
프로그래밍 언어의 함수는 일련의 괒어을 '문'으로 구현하고 {}로 감싸서 하나의 실행단위로 정의한 것이다.

```javascript
var a = function add(x,y){
    return x + y;
};
```

함수의 구성 요소는 다음과 같다

1. 함수 이름
	- 함수 이름은 식벼랒고 식별자 네이밍 규칙을 준수해야 한다.
	- 함수 이름은 함수 내부에서만 참조할 수 있는 식별자다
	- 함수 이름은 생략할 수 있다. 이름이 있는 함수를 김여함수 없는 함수를 무명/익명함수라 한다.
2. 매개변수 목록
	- 0개 이상의 매개변수를 소괄호로 감싸고 쉼표로 구분한다.
	- 함수를 호출할 때 지정한 인수가 순서대로 할당된다. 자바와 다르게 순서만 의미가 있다.
	- 매개 변수는 함수 몸체 내에서 변수와 동일하게 취급된다. 따라서 식별자 네이밍 규칙을 준수해야 한다.
3. 함수 몸체
	- 함수 호출에 의해 실행된다.

## 함수 정의법

```javascript
//1. 함수 선언문
function add(x,y){
    return x + y;
};

//2. 함수 표현식
var add = function(x,y) {
    return x + y;
};

//3. Function 생성자 함수
var add = new Function('x','y','return x + y');

//4. 화살표 함수(ES6 이상에서)
var add = (x,y) => x + y;
```

특징

1. 함수 선언문
	- 함수 리터럴과 형태가 동일하나 함수 이름을 생략할 수 없다.
	- 함수 선언문은 표현식이 아닌 문이다. 따라서 그자체를 실행시 undefined를 반환한다.
	- 표현식이 아닌 문은 변수에 할당할 수 없는데, 함수 선언문이 피연산자로 사용되는 경우가 아니라면 자바스크립트 엔진에서 표현식으로 받아들이고 변수에 할당된다.
	- 자바스크립트 엔진은 기명함수 리터럴로 되어있는 함수 선언문을 해석할 때, 암묵적으로 함수의 이름을 식별자로 생성해주고 거기에 함수 객체를 할당해준다.

```javascript
function add(x,y){
    return x + y;
};
//위의 함수는 자바스크립트에서 다음과 유사한 처리가 된다
var add = function add(x,y){
    return x + y;
};
```

2. 함수 표현식
	- 함수 리터럴의 이름을 생랴갛ㄹ 수 있다. 이러한 함수를 익명함수라고 한다.
	- 함수 표현식의 함수 리터럴은 함수 이름을 생략하는 것이 일반적이다.
	- 함수 선언문과 같이 함수를 호출할 때는 함수 이름이 아니라 함수 객체를 가리키는 식별자를 사용해야 한다. 함수 이름은 함수 몸체 내부에서만 유요한 식별자이므로 함수 이름으로 함수를 호출할 수 없다.

> 함수 표현식과 함수 선언문은 차이가 없어보이지만 둘은 표현식이 아닌 문과 표현식인 문이라는 차이가 있기에 미묘하게 다르게 작동한다.
> 함수 표현식의 경우에는 변수를 먼저 호이스팅하고 이후에 그 안에 함수 리터럴 객체를 집어넣는 형태가 되지만
> 함수 선언문의 경우에는 호이스팅에 의해 코드의 선두로 끌어올려진 것처럼 작동하게 된다.
> 따라서, 함수 선언문은 밑에 작성해도 위에서 실행시 제대로 작동하지만
> 함수 표현식은 호출문 밑에 작성하면 undefined가 들어있는 변수만을 호출하게 되므로 TypeError를 발생시킨다.
> 함수 선언문은 함수를 호출하기 전에 반드시 함수를 선언해야 한다는 당연한 규칙을 무시하기 때문에 함수 표현식을 사용할 것을 권장한다.

3. Function 생성자 함수.
	- 클로저를 생성하지 않기 때문에 함수 선언문이나 표현식과는 다르게 작동한다.
	- 클로저에 대해 알아보지 않았기 때문에 이후에 다시 알아보도록.

4. 화살표 함수
	- function 키워드 대신 =>를 사용해 좀 더 간략하게 선언하는 방식으로 항상 익명 함수로 정의한다.
	- 기존 함수와 this 바인딩 방식이 다르다
	- prototype 프로퍼티가 없다
	- arguments 객체를 생성하지 않는다.
	- 생성자 함수, this, 프로토타입, arguments 객체를 살펴본 후 이후에 다시 알아보도록

## 함수 호출

식별자(매개변수나 인수);

- 매개변수는 함수를 정의할 때 선언하며 함수 몸체 내부에서 변수와 동일하게 취급된다.
- 즉 함수가 호출되면 함수 몸체 내에서 암묵적으로 매갭녀수가 생성되고 undefined로 초기화 된 이후에 인수가 순서대로 할당된다.
- 매개변수는 함수 내부에서만 참조할 수 있다.
- 함수는 매개변수의 개수와 인수의 개수가 일치하는지 체크하지 않는다. 즉 많든 적든 에러를 발생하지 않고, 할당되지 않은 매개변수의 값은 undefined다.
- 초과된 인수는 암묵적으로 arguments객체의 프로퍼티로 보관된다.
- 함수 내부에 적절한 인수가 전달되었는지 확인할 필요가 있다.
- 인수가 전달되지 않은 경우에는 단축평가를 사용해 매개변수에 기본 값을 할당하는 방법도 있다. 혹은 매개변수 기본값을 이용할 수도 있다.
- 매개변수에 최대 개수 제한은 없지만 가능한한 적을수록 좋다. 그만큼 한가지 일에 몰두한 변수라는 뜻으로 이해하기 쉬워지니깐.

## 반환문

return 키워드와 표현식으로 이루어진 반환문을 사용해 실행 결과를 함수 외부로 반환할 수 있다.

- return 이후의 함수 내 코드는 무시당한다
- return은 생략할 수 있다. undefined를 반환한다.
- return 키워드와 반환값으로 사용할 표현식 사이에 줄바꿈이 있으면 세미콜론 자동삽입으로 인해 의도치 않은 결과가 발생할 수 있다.
- 전역에서 return 키워드를 사용시 문법에러가 발생한다. 단 node.js에서는 파일별로 독립적인 파일 스코프를 갖기 때문에 파일의 가장 바깥 영역에서 반환문을 사용해도 에러가 발생하지 않는다.

## 참조에 의한 전달과 외부 상태 변경

```javascript
function changeVal(primitive, obj){
    primitive += 100;
    obj.name = 'Kim';
}
var num = 100;
var person = { name : 'Lee' };
changeVal(num, person);
console.log(num); //100 얘는 참조주소를 보내는 게 아니라 값을 보내기 때문에 원본이 바뀌지 않는다.
console.log(person); // 'Kim' 얘는 참조 주소를 보내서 참조 주소의 프로퍼티를 바꾸라고 하기 때문에 값이 바뀐다.
```

이러한 참조에 의한 전달로 인해 객체 값이 변경되며 발생할 사이드 이팩트를 방지하기 위해 불변객체로 만들어 사용하면 된다.

## 다양한 함수의 형태

1. 즉시 실행 함수
   함수 정의와 동시에 즉시 호출되는 함수 단 한 번만 호출되며 다시 호출할 수 없다.

```javascript
(function (){
    var a = 3;
    var b = 5;
    return a + b;
}());
//맨 뒤의 ()는 함수 호출 연산자로 사용된다.
```

- 함수 이름이 없는 익명 함수를 사용하는 것이 일반적.
- 반드시 그룹연산자 ()로 감싸야 한다. 왜냐하면 함수 정의가 함수 선언문의 형식에 맞지 않기 때문이다.
- 기명으로 작성하더라도, ()로 감싸지 않으면 함수 선언문 이후에 세미콜론이 자동으로 삽입되고, 함수 선언문 뒤의 ()는 함수 호출 연산자가 아니라 그룹 연산자로 해석되고, 그룹 연산자에 피연산자가 없어서 에러가
  발생한다.
- 그룹 연산자로 감싼 이유는 함수 리터럴을 평가해서 함수 객체가 생성하기 위해서다. 따라서 먼저 함수 리터럴을 평가해서 함수 객체를 생성할 수 있다면 다른 방법을 사용해도 상관 없다.

- 즉시 실행 함수도 일반 함수처럼 값을 반환할 수 있고 인수를 전달할 수 있다.

2. 재귀 함수

- 내부에서 자기를 호출해서 반복문 없이 반복되는 처리를 구현하는 방법.
- 반드시 탈출 조건을 만들어야 한다.

3. 중첩 함수

- 함수 내부에 정의된 함수. 중첩 함수는 외부 함수 내부에서만 호출할 수 있다.

4. 콜백 함수

- 함수의 매개변수를 통해 다른 함수의 내부로 전달되는 함수를 콜백함수라고 한다. 쉽게 말해서 a함수를 정의해서 매개변수로 b함수에다 보내고, b함수는 a함수를 인수로 받아서 자기 안에서 실행시킨다.

> 여기서 a는 콜백함수, 콜백함수를 받은 함수를 고차함수 라고 한다.
> 중첩 함수와의 차이는, 중첩함수는 고정되어 있어서 교체하기 곤란하지만
> 콜백함수는 외부에서 고차함수 내부로 주입하기 때문에 자유롭게 교체할 수 있다는 장점이 있다.
> 콜백함수가 고차함수 내부에만 호출된다면 콜백함수를 익명함수리터럴로 정의하면서 곧바로 고차함수에 전달하는 것이 일반적이다.

5. 순수 함수와 비순수 함수

- 어떤 외부 상태에 의존하지도 않고 변경하지도 않는 부수효과가 없는 함수를 순수함수라고 한다.
- 부수효과가 있는 함수를 비순수 함수라고 한다.

- 순수 함수는 동일한 인수가 전달되면 언제나 동일한 값을 반환한다.
- 외부 상태에도 의존하지 않고 오직 매개변수를 통해 함수 내부로 전달된 인수에게만 의존해 값을 생성한다.
