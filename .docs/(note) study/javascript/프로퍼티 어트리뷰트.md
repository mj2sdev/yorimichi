## 내부 슬롯과 내부 메서드
ECMA 사양에서 나오는 [[]]로 감싸여 있는 것이 내부 슬롯과 내부 메서드  
(의사 프로퍼티persudo property와 의사 메서드persudo method라고 부른다)

이들은 개발자가 직접 접근할 수 있도록 외부에 공개된 객체의 프로퍼티가 아니다  
단 일부에 한해서 간접적으로 접근할 수단을 제공한다.  

예로 모든 객체엔 [[property]]라는 내부 슬롯이 있는데 이에 직접 접근할 수 없지만, __proto__를 통해 간접적으로 접근할 수 있다.

## 프로퍼티 어트리뷰트 프로퍼티 디스크립터 객체
자바스키립트 엔진은 프로퍼티를 생성할 때 프로퍼티 상태를 나타내는 프로퍼티 어트리뷰트를 기본값으로 자동 정의한다. (프로퍼티의 값, 값의 갱신 가능 여부, 열거 가능 여부(emnumerable), 재정의 가능 여부)

각각의 어트리뷰트는 [[Value]], [[Writable]], [[Enumerable]], [[Configurable]]이다.  
따라서 프로퍼티 어트리뷰트에 직접 접근할 수 없지만 Object.getOwnPropertyDescriptor 메서드를 사용하여 간접적으로 확인할 수 있다.

- Object.getOwnpropertyDescriptor(객체식별자명);  
> 프로퍼티 디스크립터 객체를 반환. 존재하지 않는 것은 undefined로 반환한다.

프로퍼티는 데이터 프로퍼티와 접근자 프로퍼티로 나뉜다  
데이터는 키와 값으로 구성된 우리가 아는 프로퍼티.  
접근자는 값을 갖지 않지만 읽거나 저장할 때 호출되는 접근자 함수로 구성된 프로퍼티  

데이터 프로퍼티
앞서 말한 4개  
[[Value]]  
> 프로퍼티 키를 통해 반환되는 값  
[[Writable]]  
> 불리언 값. false는 읽기 전용
[[Enumerable]]  
> 불리언 값 false는 for...in 문이나 Object.keys 메서드 등으로 열거할 수 없다.
[[Configurable]] 
> 불리언 값. false는 삭제와 변경이 금지된다. 단 writable이 true인 경우 value의 변경과 writable을 false로 변경하는 것이 허용된다.

접근자 프로퍼티.

[[Set]]
