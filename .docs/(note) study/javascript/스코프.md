# 스코프란

스코프란 어떠한 식별자가 자신이 선언된 위치에 따라서 결정되는 참조될 수 있는 범위.

함수코드블럭{}을 기준으로 영역이 바뀐다.  
가장 바깥 영역에 선언된 것을 전역  
코드블럭 안에 선언된 것을 지역이라 하며  
전역 외의 모든 스코프는 지역이라고 보면 된다.

함수 안에 함수를 작성할 수 있는데  
이러한 경우를 함수의 중첩이라고 말하며,  
함수 안에 쓰여진 함수는 중첩함수  
중첩함수를 갖고있는 함수는 외부함수 라고 말한다.

스코프는 앞선 특징 때문에 전역에서부터 가장 깊은 중첩 함수까지 계층적 구조를 가지며  
깊은 지역쪽을 하위 스코프, 전역쪽으로 갈수록 상위 스코프라고 부른다.  
이러한 구조로 연결된 것을 스코프 체인이라 부르며  
스코프체인은 무리적 실체가 존재해서 렉시컬 환경을 실제로 생성한다.

하위스코프에서는 상위스코프를 자유롭게 참조할 수 있지만  
상위 스코프에서는 하위 스코프에서 유효한 변수를 참조할 수 없다.

## 함수레벨 스코프

자바는 함수 블럭 말고도 if문 같은 제어문 내에서의 선언도 스코프 범위로 인정해주기 때문에 전역 변수와 같은 이름의 변수를 만들어도 지역 변수로서 하나의 변수가 생겨난다.  
하지만 함수레벨 스코프를 지원하는 언어에서는 함수 블럭만을 스코프 범위로 인정하기 때문에 제어문 내에 var로 선언된 변수는 지역변수가 아닌 전역변수로 선언되고, 같은 이름의 전역변수가 이미 존재했던 경우에는
재할당된다.

## 렉시컬 스코프

```javascript
var x = 1;

function a() {
    var x = 10;
    b();
};

function b() {
    console.log(x);
};

a(); //1
b(); //1
```

위 결과에서 둘 다 1이 나오는 이유.  
함수를 어디서 호출했는지가 아니라 함수를 어디서 선언했는지에 따라서 함수의 상위 스코프가 결졍되기 때문.  
쉽게 생각해서 자바와 같다.
